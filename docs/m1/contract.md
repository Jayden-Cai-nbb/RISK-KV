# M1 服务协议合同

版本：2026-11-07协作快照。当前实现为`rtl/m1/`与`platform/m1/`，验证进展见[状态页](../status.md)。

范围固定为完整 Qwen3-0.6B、原生数值、一个对象、两查询、256-token 前缀、每查询三步。布局唯一输入为 `configs/m1/layout.json`。核心与 fast 目标分别 50/100 MHz，相位关系由目标平台验证。

## 状态归属与事务

命令适配层仅持有 MMIO 暂存参数和响应，监督控制器持有 session、epoch、sequence、generation、对象状态、绑定引用、任务身份快照、CQ 和逻辑进度。计算执行器持有装载/ARM/RUN、结果收集与排空状态；清理器持有范围索引、地址和已发/已退休计数。平台存储适配层持有实际在途请求，不受 CPU 或任务复位影响。

命令在 core 上升沿 `cmd_valid && cmd_ready` 接收并冻结全部身份和参数。只允许一笔命令；提交序号严格递增，拒绝不推进序号。session 非零，epoch 来自监督器，generation 由硬件单调推进；sequence全1时拒绝命令，generation全1时拒绝REGISTER，epoch耗尽时受控复位隔离；身份不回绕复用。BOOT 建立主机提供的启动身份，板级冷启动必须提供新身份。

完成可见是 `cq_valid` 上升，消费是身份匹配的 ACK 接收沿。CQ 内容在等待期间保持。BUILD/DECODE 仅在成功消费沿推进逻辑进度；不能用结果写回、HALT 或 CQ 可见代替消费。失败任务逻辑增量为零。取消与完成同沿取消优先，错误优先于取消。取消在 CQ 成功发布后被拒绝，保持既有完成内容稳定。

普通取消使整个对象不可服务，任务自然结束并排空后发布失败 CQ。消费后允许 RECOVER，整对象清理后进入可注册状态。正常 RELEASE 清理双尾及共享工作区，保留封存前缀；消费完成后解除绑定，随后可 BIND。RETIRE 清理整对象及工作区，消费完成后退役。REGISTER 分配新代际。

受控复位由独立请求进入监督器，立即关闭新任务和逻辑提交，等待当前计算及存储退休，恢复整对象和工作区，再推进 epoch、清除会话并复位 CPU。既有 CQ 不提交；旧返回先物理排空。任何阶段无法退休，超时隔离并保留在途证据，必须板级冷启动；CPU 复位不能解除隔离。

## 清理与存储合同

清理器使用独立、无缓存、128-byte 事务接口：地址为 32-bit **字节地址**，数据低字节对应低地址，写掩码一位一字节。请求在 valid/ready 沿接受，阻塞时完整负载保持；响应为独立 valid/ready，每笔请求恰好一笔响应，无乱序。写响应代表实际对后续 NPU/主机可见的写入退休，不能仅代表桥接器已接受。错误响应也退休该笔事务，但不能赋予清理资格。

首版清理器最多一笔在途，优先可验证性。单个请求包括一次读或一次写；复制恢复每 128 B 先读后写。计数为 64-bit，读写接受与退休分别计数。清理成功需要全部描述符完成、计数守恒、平台 fabric_idle 连续两拍及显式 cache_flush_ack。软件不能伪造清理成功。清理时 NPU 停止，主机不能并发访问；模式变换先通过同一排空屏障。

双尾 30,277,632 B，整对象 45,416,448 B 均写零。另恢复三个非权重工作区，原始内容直接从冻结冷镜像抽取到 `0x61000000` 起的只读模板。此地址位于旧镜像末尾之外、2 GiB 范围内；不移动原模型、KV 或程序地址。模板与程序、权重均须主机装载校验后保持不变。工作区恢复包含 prompt，但本阶段固定同一文档；不同文档输入接入需要另定主机装载合同。

模板恢复负责DDR初值。当前固定程序的片上状态读前覆盖审计及完整持续服务数值仿真已完成，分别见里程碑证据；新程序仍需重新核对覆盖。

## 快测验收与边界

清理测试必须区分请求接受和写入退休，覆盖背压、延迟、错误、响应丢失、失效不应答及迟到返回。响应丢失时不能重新分配或重发引起重复副作用。冷复位只在平台确认全设备复位后使用，普通控制复位不会连接到清理器或 DDR 队列 reset。

控制测试包含延迟消费、错身份、重复命令、取消/错误/完成竞争、释放后重绑、恢复后代际变化、复位保留内存，累计至少 10,000 个控制事务。完整数值集成只在快测通过、实现冻结后执行一次；失败保留首个差异，局部定位后再重跑。

真实平台采用VU440、固定Vivado2022.2与实验DDR配置；独立DDR数据测试已完成，最终整机验收见[状态页](../status.md)。
