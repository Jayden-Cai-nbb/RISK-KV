# 当前状态与继续位置

版本日期：2026-11-07。当前发布为固化开发快照，配置标识`M1-experimental-demo`。

## 已完成

- 完整模型RTL连续服务仿真：64次构建、两组双查询各三步续算，中间清尾与再次绑定；全部有效KV/logits及不可变区符合参考。
- 独立DDR实物：10次配置级冷启动、全2 GiB六阶段读写、112轮压力（1837.498秒）、84处独立主机读回。原始归档3160项摘要匹配。
- 最终整机布局布线：`rkv_m1_board_top`，Vivado2022.2，`xcvu440-flga2892-1-c`。WNS **+0.302 ns**、WHS **+0.013 ns**、WPWS **+0.138 ns**，setup/hold失败端点均0，内部未约束端点0。
- 布线后CDC：Critical 0；CDC-6 Warning 6、CDC-15 Warning 470。原报告见`evidence/implementation/cdc.rpt`。

## 当前关口

最终物理审查仍需完成CDC告警逐类核对、异步外部复位输入`sys_rst_n`及DDR RESET_n输出的时序合同审查。工具报告的正slack说明已施加约束满足，不替代这些接口条件。

最终整机尚未在板上运行。板上最近已验证配置为独立DDR检查位流。配对最终bit/ltx、同一位流DDR复验、完整模型实物数值、持续服务与视频为接续任务。

## 下一步

1. 使用`board_review`提取最终检查点的时钟、复位端点和层级资源；审查原始报告与例外依据。
2. 物理关口闭合后通过`board_bit`生成配对bit/ltx，并绑定源码、固件、参数、实现报告摘要。
3. `board_qualify`完成最终位流的10次配置冷启动、全范围数据、30分钟压力及独立读回。
4. `board_suite`按装载→四-token→完整前缀与连续查询→异常恢复→收益对照推进。
5. `experimental_acceptance`汇总数值、样本数量及证据一致性，再录制正式演示。

本版使用48 MHz输入、MIG内部单级MMCM实验配置；MIG输入支持范围、实际模块部分时序及实体速度级仍列为开放平台条件。实现采用保守`-1-c`，并不据此认定实体速度级。正式M1-board与实验验收使用不同状态标签。

## 版本绑定

当前硬件CSR实验身份继承完成综合的源码集合；随后约束修订与布线结果单独绑定输入摘要和最终位流。CSR身份不是位流文件完整摘要。发布源码另由`publication/manifest.json`绑定；已有里程碑保持其原输入身份。
