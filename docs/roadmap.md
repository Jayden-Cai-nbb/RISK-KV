# 应用方向与技术路线

## 应用定位

首个应用方向是固定短资料的重复查询：同一设备手册、实验室规则或产品说明被多次提问，资料前缀构建一次，各问题使用私有尾部。设备侧RISC-V组织服务流程，硬件维护身份、进度与回收条件。

当前冻结负载验证计算与管理行为。完整问答需要文本导入、tokenizer与对话模板、动态问题、持续生成/EOS、上下文与输出容量扩展，以及依据资料回答的质量评价。主机承担文本处理和显示；模型前向计算与KV访问由FPGA完成。

## 分阶段路线

| 阶段 | 交付能力 | 验收目标 |
| --- | --- | --- |
| M1：共享资料管理演示台 | 最终整机真实DDR计算、连续复用、取消回收、恢复 | 最终位流DDR检查、完整KV/logits、100批查询、10次重建、每类异常10次、30批双策略对照 |
| M2：固定资料完整问答 | 任意问题输入、完整回答、可取消生成 | 同题软件参考、答案依据/正确性/无答案拒答评价、实测首token与完整回答时延 |
| M3：长会话与分支 | 可变上下文、分支引用与取消恢复优化 | 与静态批处理/保守取消比较，验证引用保护与回收成本 |
| M4：多资料容量管理 | 多对象分配、热点保留、驱逐与调度 | 与静态热点/分组策略比较，报告命中、队列、容量及管理成本 |

## 当前不足与处理顺序

1. 最终NPU＋MIG的物理实现与板上数值验收仍是近期主线，最新状态见[状态页](status.md)。
2. 48 MHz实验配置超出MIG官方输入支持条件；实体速度级和部分模块时序尚待核验。实验通过后仍需支持范围内的平台配置与温压评估，才能形成正式板级结论。
3. 单对象、固定双查询、固定256-token和三步续算限制应用范围；扩展必须同时更新程序、布局、固件及测试。
4. 整区清理与自然结束取消可能增加恢复时延；先测成本，再选择局部清理或抢占。
5. JTAG可能主导装载和结果回传；先测小块与全量吞吐，再评估PCIe等接口，保留同一硬件合同。
6. 完整模型参考共享上游算术/编译器，应用质量尚未评价；补充独立数值验证和真实资料问题集。

多资料检索/RAG会改变每次模型输入的资料前缀。其缓存命中与复用收益需要单独测量，不能从固定资料结果直接外推。
