# 实物展示与验收方案

展示围绕三个问题：重复工作能否省掉，取消会不会留下脏状态，下一次服务还可靠吗。

| 场景 | 实际操作 | 展示证据 |
| --- | --- | --- |
| 重复查询 | 每批重建对比前缀复用，各至少30批，固定模型/资源/输入 | 构建次数、设备周期、清理字节、主机端到端中位数/p95 |
| 安全取消 | 在途取消→零逻辑提交→自然结束/排空→清理→再次服务 | 身份、提交增量、在途数、清理退休、恢复后的完整数值比较 |
| 持续运行 | 100批查询、10次重建、取消/错误/受控复位各10次 | 逐批结果、对象代际、首错、不可变区及完整汇总 |

当前可展示结果及操作见[实物验证](board-validation.md)、[录制操作单](m1/record-now.md)和[token文本报告](m1/token-results.md)。只读展示分别标识实时快照、已完成事件与现场原始数据复核；完整验收保持独占连接。

## 画面组织

5–8分钟讲解版保留一段连续的“发命令→硬件状态改变→原始读回比较”，原始录屏和运行日志另存。

1. 实拍VU440、Kingston、供电与JTAG连接，关联本次运行编号。
2. Vivado显示器件、配对bit/ltx与活体心跳、DDR校准。
3. 终端执行前缀构建和两组查询，展示清尾后复用同一封存前缀。
4. 展示在途取消、排空、清理及恢复结果。
5. 打开原始比较与成本表，解释管理机制、代价与适用场景。

网页作为操作和汇总入口；VIO为状态观察，轮询不表述为逐周期采样。Vivado GUI和自动服务使用同一硬件独占约束，分阶段转交控制连接。当前会话读回与历史验收分别显示。

## 验收关口

A：独立DDR证据收尾。B：最终整机STA/CDC/复位/DRC与119引脚核对。C：同一最终位流10次配置级冷启动、全2 GiB、30分钟压力和独立读回。D：完整镜像校验、四-token完整28层、256-token及两组查询。E：持续服务和异常恢复。F：同资源收益对照与交付。

四-token失败时停止扩大负载。永久失联测试置于批次末尾，之后整链冷启动并重新装载。验收模式完整比较KV/logits；演示模式读取token和必要状态，报告明确本次检查范围。三步token用于计算验证。

装载允许在录制前完成，保留真实耗时与校验记录；等待的剪辑标明时间跳转。最终结论为“实验性实物演示通过”或具体未通过关口。
